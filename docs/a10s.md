# A10s

Samsung Galaxy A10s antigo reaproveitado como servidor pessoal. O Termux mantém os serviços no celular; o notebook permite acessar e administrar a instalação. A Rota é a automação de transporte universitário executada nesse ambiente.

## Acesso

Com Tailscale e MagicDNS ativos no notebook, abra **http://a10s:8787**. O endereço anterior por IP continua disponível. A porta 80 não é acessível ao processo sem privilégio no Android deste aparelho; não foi concedido root nem aberto acesso público.

O nome curto exige a configuração de DNS da rede privada. A aplicação aceita apenas o endereço configurado e aliases privados explícitos. Requisições de alteração precisam de origem correspondente ao endereço utilizado, sessão e token de proteção. Abrir pelo nome pode exigir um novo login.
